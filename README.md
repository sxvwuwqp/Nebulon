# Nebulon 编程语言官方使用文档

## 文档版本：V1\.0 正式版

## 适用对象：NebulaOS 全栈开发者

# 一、语言概述

Nebulon 是一款**零运行时、静态编译、内核级安全**的现代化系统编程语言，专为自研裸机操作系统 NebulaOS 设计。语言定位为**下一代内核开发语言**，在完全兼容标准 C 内核 ABI、保持原生裸机极致性能的前提下，解决传统 C 语言开发内核存在的安全性差、资源管理混乱、可读性低、无编译校验、易崩溃等一系列工程痛点。

Nebulon 不依赖虚拟机、不携带运行时、不包含垃圾回收机制，所有高级语法全部在编译期静态降级为原生机器码，运行效率与手写 C 内核代码完全一致。

Nebulon 配套专属自研编译工具链 **Aether Compiler**，形成完整闭环自研生态：NebulaOS 系统、Nebulon 语言、Aether 编译器。

# 二、核心设计理念

- **性能无损**：零运行时、零间接层、零运行时开销，100% 对标原生 C 性能。

- **内核安全优先**：编译器内置内核上下文校验机制，在编译阶段拦截非法内核行为。

- **编译期驱动**：反射、解析、模板、资源管理全部编译期完成。

- **原生内核适配**：语法、并发、内存模型完全对接 NebulaOS 内核调度与硬件模型。

- **跨平台极简开发**：全平台统一 SDK，无需复杂编译环境搭建。

# 三、核心技术能力

## 3\.1 编译期零开销元编程

Nebulon 支持完整的编译期元编程能力，包含结构体反射、类型判定、字段遍历、静态配置绑定。所有元数据仅参与编译分析，不会打包进最终二进制，实现真正的零成本反射。同时原生支持 JSON、XML、Protobuf 静态解析，无需第三方库依赖。

## 3\.2 内核静态安全校验机制

Aether 编译器内置内核状态机检测，严格区分内核上下文场景，杜绝内核非法操作：

- 中断上下文禁止阻塞、等待、睡眠操作

- 无堆内核场景禁止动态内存分配

- 非法任务调度、非法资源占用直接编译报错

从编译根源防止内核死锁、空指针、内存滥用、任务异常导致的系统宕机。

## 3\.3 全自动资源生命周期管理

Nebulon 内置作用域资源托管机制，替代 C 语言手动资源释放：

- scope 自动释放局部资源

- guard 自动解锁内核锁、设备锁

- taskset 自动归集、等待、释放内核任务

彻底解决内核开发常见的内存泄漏、句柄泄露、死锁、任务残留问题。

## 3\.4 原生内核并发语法

Nebulon 提供现代化并发语法，编译后直接映射为 NebulaOS 内核原生调度原语，无任何封装损耗：

- launch 启动内核任务

- await 内核事件等待与多路复用

- parallel 批量并发调度

# 四、工具链与 SDK 体系

## 4\.1 编译器介绍

Aether Compiler 是 Nebulon 专属静态 AOT 编译器，前端全部纯 C\+\+20 自研，语法解析、AST 构建、语义校验、安全检测、元编程展开完全自主可控，仅复用轻量化机器码优化模块，无版权风险、无生态依赖。

## 4\.2 跨平台 SDK

Nebulon 官方提供 Windows、macOS、Linux 三平台独立预编译 SDK 包。开发者无需安装 GCC、Clang、CMake、LLVM 等任何编译环境，下载解压即可完成开发与编译。

SDK 内置：成品 Aether 编译器、NebulaOS 专属链接器、内核静态库、全套内核/用户态头文件、标准链接脚本、环境启动脚本。

# 五、编译产物说明

Nebulon 仅产出适配 NebulaOS 的专属二进制，不兼容 Windows、macOS、Linux 宿主系统：

- **内核态产物：\*\.ko 驱动模块**，用于硬件驱动、内核模块、中断服务开发

- **用户态产物：静态 ELF 程序**，用于系统服务、应用程序、工具程序开发
